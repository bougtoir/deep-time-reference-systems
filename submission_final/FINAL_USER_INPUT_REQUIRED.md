# Final user input required

Complete locally before uploading to Earth Science Informatics:

1. affiliation and postal address (title page, manuscript title block, cover letter);
2. ORCID, or explicit omission;
3. funding statement (Statements and Declarations);
4. competing-interests statement (Statements and Declarations);
5. choose the publishing route (subscription or open access; APC not verified here).

No scientific result depends on these entries.

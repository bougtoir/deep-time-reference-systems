## Reproduction

```bash
make reproduce   # data, analysis, manuscript, lint, tests, ZIP verification
```

All manuscript numbers are read from `results/manuscript_values.csv`, generated by `scripts/run_pipeline.py`. Decode-time values (`rec_cost_*_median_decode_ms`) are wall-clock measurements and vary between runs; every other value is seeded and deterministic up to the floating-point noise floor documented in `RESULT_CHANGELOG.md`.
